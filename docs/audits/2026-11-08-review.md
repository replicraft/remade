## Important audit findings and limits

- **LightCraft:** upstream withdrew compressed Olympus ORF decoding pending a provenance review and withdrew earlier clean-room/verification claims for that work. The listing now states that restriction. This review does not certify provenance or make a legal determination.
- **PCBCraft:** current source documents an earlier KiCad-inspired schematic/footprint foundation; the former routing, board export and production layout claims no longer describe it. Routing, full ERC/DRC and fabrication output remain planned. The existing broader Altium scope is retained without adding an already-open-source KiCad target.
- **encoderCraft:** source decoding is connected to export now; the old blank-frame/silent-audio limitation is obsolete. Its production-ready headline is not accepted as general runtime qualification.
- **OxyBrush:** real parser and app dispatch support bounded ZTL/ZPR mesh import, while some research docs/crate comments still describe Milestone 0. Full native project fidelity and writing remain unverified.
- **DashCraft:** dated gap updates and source show bounded editing and PBIP saves despite a stale read-only README headline. Full report/model editing and PBIX writing remain absent.
- **MisterDiagram:** beta builds and a November 4 M5 completion coexist with a pre-alpha/M5-open roadmap summary. Retain the conservative stage pending upstream reconciliation; the ledger records both statements.
- **Flare:** complete YAML held unchanged. The current repository has only a nightly prerelease, not the requested replacement v0.1.0 release.
- **Armada:** source reviewed through its existing documented GitHub mirror; the primary host’s JavaScript shell is not proof of source or mirror freshness.
- **RollTop/Hexe:** intended licensing without a current grant, and the earlier binary-analysis process question, respectively, remain explicit upstream ambiguities.
- **License-text gaps:** Drop, GameDepot and LaserCraft retain documented license declarations without standalone applicable license texts; no legal grant certification is inferred. OpenPlayground has no license recorded.
- Source/documentary checks are distinct from running all apps, testing proprietary files or hardware, or conducting security/legal/provenance certification. No upstream code executed. Tests remain in CI under AGENTS.md.
